# Portofolio Personal - Submission Dicoding

Submission untuk tugas akhir kelas **Belajar Dasar Pemrograman Web** dari Dicoding Indonesia. Website ini merupakan portofolio personal yang dirancang dengan standar kualitas tinggi, mengedepankan aspek semantik, estetika, dan responsivitas.

- **Nama:** Ahmad Ambari
- **GitHub:** [RyzZ](https://github.com/Rynnsza)
- **Tujuan:** Submission Tugas Akhir Dicoding

## 🚀 Fitur Unggulan
- **Modern & Premium UI:** Desain bertema *Dark Mode* dengan perpaduan efek *Glassmorphism* dan *Mesh Gradients*.
- **Semantic HTML5:** Implementasi tag semantik (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`) secara tepat untuk SEO dan aksesibilitas.
- **Flexbox Layout:** Seluruh tata letak dibangun menggunakan CSS Flexbox secara murni (tanpa Float).
- **Responsive Web Design:** Tampilan yang optimal di berbagai perangkat melalui penggunaan Media Queries.
- **Interaktivitas JavaScript:**
    - **Active Menu Highlight:** Menu navigasi yang berubah secara otomatis sesuai posisi scroll.
    - **Scroll Reveal:** Animasi konten yang muncul secara dinamis saat di-scroll.
    - **Magnetic Buttons:** Tombol hero yang interaktif mengikuti pergerakan kursor.
    - **Sticky Capsule Navbar:** Navigasi melayang yang berganti ukuran secara halus saat scroll.

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Struktur konten semantik.
- **CSS3:** Styling premium dengan variabel CSS, animasi, dan Flexbox.
- **JavaScript (Vanilla):** Logika interaktivitas dan manajemen DOM.
- **Google Fonts:** Menggunakan *Plus Jakarta Sans* dan *Outfit*.
